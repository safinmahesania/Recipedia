Recipedia · UI Kit 05 — your blend

House Blend

Type from Garnish. Splash and screens from Pantry. Dark theme from Ember. Food slots now carry two-tone illustrations instead of line icons, and every tint is a gradient. Toggle Light / Dark above — all 21 screens switch.

Plus Jakarta Sans + InterIllustrated food slotsGradient tintsCharcoal + gold at night
01Illustrations

Eight two-tone illustrations, one per category, drawn as SVG so they scale from a 28px list thumbnail to a full-width detail header without blurring. Each takes its colours from the tile it sits in, so the set restyles itself in dark mode instead of needing a second set.

And 41 coloured ingredient illustrations — fruit, vegetables, dairy, spices and drinks — used in pantry chips, ingredient lists and the shopping list. The powders, seeds and leaf sprigs are each ONE drawing recoloured — that is how 157 real ingredients reduce to about 35 shapes to draw.

Why illustrations rather than photos. These are drawn, so there is no licensing question and nothing to load from a blocked host — and because they are vector and colour-inherited, one file covers light mode, dark mode and every size. They also make the empty state look intentional: a grid of illustrated tiles reads as a design decision, a grid of broken photo frames reads as a bug. When real photography arrives it drops into the same fixed-ratio slots and the illustrations become the fallback.

Still open: the accent flips between modes — mint by day, gold by night. Toggle and see whether that reads as a signature or an inconsistency.
